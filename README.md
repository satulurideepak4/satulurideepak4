## 🏗️ What I've Built

**API Gateway & Microservices Platform**
Designed and delivered 12+ production microservices in Java/Spring Boot/Spring Cloud, load-tested for high-throughput gateway traffic with sub-200ms average latency, covering API versioning, resiliency, and fault isolation.

**Kafka Event Pipelines**
Built event-driven pipelines handling tens of thousands of messages per second, with dead-letter queues, retry handling, and consumer-lag observability via Grafana.

**RAG Documentation Search**
Built a Retrieval-Augmented Generation pipeline (Spring AI, Python, FastAPI, pgvector) that chunks, embeds, and retrieves internal documentation to generate grounded, contextual answers, replacing manual doc lookup.

**LLM-Integrated API Tooling**
Built an LLM-integrated request-generation feature for an internal API client that turns plain-language prompts into working requests, test scripts, and variable extraction, backed by a configurable multi-model backend (Anthropic, OpenAI, Gemini).

**Multi-Cloud Cold Storage Pipeline**
Built a nightly archival pipeline moving records across AWS S3, Azure Blob, and GCP Cloud Storage, secured with AES/RSA encryption, cutting long-term storage costs significantly.
